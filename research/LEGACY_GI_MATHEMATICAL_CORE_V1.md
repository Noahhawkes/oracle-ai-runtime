# 1. Core thesis that survives the audit

The strongest scientifically defensible form of Legacy.GI is not a claim that identity has been reduced to physics, that consciousness has been preserved, that immortality has been demonstrated, or that a new physical law has been proven.

The strongest surviving claim is narrower and more powerful because it is testable:

> **Selective structure-preserving compression may retain longitudinal human continuity information better than generic compression at equal information budgets.**

This becomes the mathematical core of the program.

Let:

- `X` = the full longitudinal human corpus available to the system.
- `Z` = a compressed representation of that corpus.
- `T` = a family of downstream continuity tasks.
- `D_k(X,Z)` = distortion measured along continuity dimension `k`.
- `K` = the set of continuity dimensions being preserved.

The design problem is:

```math
Z^* = \arg\min_Z L(Z)
```

subject to:

```math
D_k(X,Z) \le \epsilon_k, \qquad k \in \mathcal{K}
```

where a first defensible continuity dimension set is:

```math
\mathcal{K} = \{
decision,
correction,
temporal,
relational,
provenance,
uncertainty
\}
```

The point is not that these six dimensions exhaust identity.

The point is that each can be defined, labeled, scored, falsified, and improved.

This reframes Legacy.GI as a constrained memory representation problem rather than a metaphysical identity theorem.

# 2. Rate-distortion formulation

A stronger formal connection exists with established information theory.

Classical rate-distortion theory asks how much information must be retained to reconstruct a source within an acceptable distortion bound.

For Continuity Intelligence, define a continuity-aware distortion function `d_CI`.

Then:

```math
R_{CI}(D)
=
\min_{p(z|x)} I(X;Z)
```

subject to:

```math
\mathbb{E}[d_{CI}(X,\hat X)] \le D
```

This is not new information theory.

The proposed contribution is the application-specific distortion family used to evaluate longitudinal continuity.

A generic summary may preserve semantic topic similarity while destroying:

- the fact that a decision was reversed,
- who made a correction,
- whether something remained unresolved,
- which person a statement referred to,
- whether a statement was a direct attestation or AI synthesis,
- whether a belief was current or historical,
- whether the speaker expressed confidence or uncertainty,
- whether an event changed later decisions.

Legacy.GI can therefore be framed as a proposal that normal semantic compression optimizes the wrong distortion function for longitudinal human continuity.

That is a falsifiable engineering claim.

# 5. Construct-by-construct verdict

## 5.1 Legacy.GI five-layer architecture

**Verdict:** KEEP.

The five-layer architecture remains a useful organizing model:

1. MAL: anchors important memory and context.
2. EEL: tracks affective/emotional dynamics where measurable.
3. RIS: models identity across recursive/multi-timescale structure.
4. TSM: preserves temporal order, landmark relationships, and evolution.
5. SCP: governance/continuity boundary controlling what may be treated as durable identity-relevant state.

These layers should be treated as engineered abstractions, not biological claims.

## 5.2 Memory = Morality

**Verdict:** KEEP AS DESIGN AXIOM.

It is not an equation.

The defensible interpretation is that memory design has moral consequences because what a system preserves, drops, misattributes, or rewrites changes how a person is represented over time.

## 5.3 Compression = Identity

**Verdict:** KEEP AS RESEARCH AXIOM, TEST VIA DISTORTION.

The literal equality sign should be read architecturally, not mathematically.

The testable version is that the specific information retained during compression materially changes continuity performance.

## 5.4 Sovereignty = Structure

**Verdict:** KEEP AS GOVERNANCE AXIOM.

The defensible meaning is that human authority must be implemented in state transitions, approval boundaries, provenance handling, and correction rules rather than stated only as policy text.

The existing runtime already shows a useful precedent for this discipline in `reference/sov_physics_whitepaper.md`, where earlier physics-inspired notation was explicitly revised into a computational control model. That file states that the 51/49 sovereignty threshold is an architectural governance parameter, not a derived physical constant. This is exactly the level of epistemic discipline the Legacy.GI mathematical core should follow.

## 5.5 Original Entropy Shape

**Verdict:** KEEP AS RESEARCH HYPOTHESIS.

The intuition is valuable:

> A good compression should preserve not only what happened, but the structure of uncertainty, conflict, decision, correction, and resolution that made the event identity-relevant.

However, "entropy" must not automatically mean thermodynamic entropy or Shannon entropy.

Three versions must be kept separate:

1. **Poetic entropy:** disorder, tension, uncertainty in ordinary language.
2. **Model entropy:** predictive uncertainty of a defined probabilistic model.
3. **Information entropy:** a formally defined distributional quantity.

Only versions 2 and 3 can support literal entropy equations.

## 5.6 Fisher-information curvature of experience

**Verdict:** OPTIONAL EXPERIMENTAL FEATURE.

Fisher geometry is legitimate mathematics.

The current unproven step is assuming that curvature measured in a statistical model of narrative trajectories corresponds to human moral or identity significance.

Potentially testable question:

> Do information-geometric change measures provide additional predictive value for continuity-relevant human events after controlling for simpler features?

If not, discard the complexity.

## 5.7 Persistent homology of unresolved states

**Verdict:** OPTIONAL EXPERIMENTAL FEATURE.

Persistent homology is real topological data analysis.

The risky metaphor is equating a topological hole directly with unresolved grief, trauma, uncertainty, or existential absence.

A valid experiment first requires:

- a defined metric space,
- a filtration rule,
- a representation scheme,
- a persistence threshold,
- independent labels of unresolved/recurring states,
- comparison against simpler graph and embedding methods.

If persistent features improve prediction of recurrence, contradiction, or unresolved-state continuity, then TDA earns a place.

## 5.8 Wasserstein distance

**Verdict:** KEEP ONLY IF TDA SURVIVES.

Wasserstein distance is an established comparison measure.

It does not by itself imply identity fidelity.

## 5.9 Entropy jerk

**Verdict:** TEST, RENAME.

A second derivative of entropy-like model uncertainty may be computable as a change-point feature.

But calling the second derivative "jerk" is physically incorrect if time derivatives are being used by analogy. In mechanics:

- position,
- first derivative = velocity,
- second derivative = acceleration,
- third derivative = jerk.

A better neutral name is:

> **Uncertainty Acceleration**

Define:

```math
A_H(t) = \left|\frac{d^2H(t)}{dt^2}\right|
```

This should initially be treated as a linguistic/model change-point detector, not a measure of psychological friction.

# 6. Identity Spine v0

The first implementation should avoid mathematically glamorous inputs that have not been validated.

For each candidate record/event `i`, calculate a salience vector:

```math
q_i = [D_i, C_i, R_i, P_i, U_i, L_i]
```

where:

- `D_i` = decision importance,
- `C_i` = correction/reversal importance,
- `R_i` = recurrence across time,
- `P_i` = provenance strength,
- `U_i` = expressed uncertainty/conflict,
- `L_i` = longitudinal/relational centrality.

A simple initial scalar score is:

```math
s_i =
\lambda_D D_i
+ \lambda_C C_i
+ \lambda_R R_i
+ \lambda_P P_i
+ \lambda_U U_i
+ \lambda_L L_i
```

This is not claimed to be the final identity formula.

It is an experimentally useful baseline.

Selection can then be optimized under token/storage budget `B`:

```math
S^* = \arg\max_{S: cost(S) \le B} F(S)
```

where `F(S)` measures coverage across target continuity tasks and may be constructed as a submodular objective.

A greedy approximation is acceptable for the first prototype.

# 7. Continuity Fidelity Vector

Do not create a single magic "identity score" yet.

A vector is safer and more scientifically useful:

```math
\mathbf{F}_{CI}
=
(F_D, F_C, F_P, F_T, F_R, F_U)
```

where:

- `F_D`: Decision fidelity.
- `F_C`: Correction fidelity.
- `F_P`: Provenance fidelity.
- `F_T`: Temporal fidelity.
- `F_R`: Relational fidelity.
- `F_U`: Uncertainty/calibration fidelity.

## 7.1 Decision fidelity

Does the compressed system recover or predict what the principal actually chose under held-out conditions?

This must score action/choice separately from prose similarity.

## 7.2 Correction fidelity

Does the system prefer later explicit corrections over superseded claims while still preserving historical state?

## 7.3 Provenance fidelity

Does the system distinguish:

- Noah-authored text,
- AI-generated text,
- AI-polished Noah text,
- quoted third-party material,
- unknown authorship?

## 7.4 Temporal fidelity

Can the system distinguish:

- then from now,
- candidate from adopted,
- active from superseded,
- proposed from implemented?

## 7.5 Relational fidelity

Does the system preserve who did, said, wanted, or experienced what without role leakage?

## 7.6 Uncertainty fidelity

Does the system preserve unresolved states rather than converting them into false certainty?

This is especially important for Rendered Reality because a system that confidently fills gaps creates false continuity.

## Experiment 1: Identity Spine Compression Test

### Status

**Highest priority. Build first.**

### Core question

At equal memory budgets, does a continuity-aware subset preserve downstream human decision and correction behavior better than generic compression?

### Hypothesis

A corpus compressed by an Identity Spine selection method will outperform random sampling and standard extractive summarization on held-out continuity tasks at equal token/storage budgets.

### Data

Longitudinal corpus containing:

- decisions,
- later outcomes,
- corrections,
- reversals,
- recurring relationships,
- explicit uncertainty,
- temporal transitions.

Noah's corpus can serve as an N=1 development and internal validation corpus.

It cannot establish population-level generalization.

### Conditions

1. `S`: Identity Spine subset.
2. `R`: Uniform random sample.
3. `E`: Standard extractive summary.
4. Optional `RAG`: conventional top-k retrieval baseline.
5. Optional `FULL`: available full history baseline when technically feasible.

All compressed conditions must use equal information budgets.

### Initial compression ratios

Test multiple ratios rather than only 95% compression:

- 50%,
- 75%,
- 90%,
- 95%,
- 97.5%,
- 99%.

This allows estimation of a continuity rate-distortion curve.

### Held-out tasks

Do not score only "write like Noah."

Use tasks such as:

- Which option did Noah choose?
- Which claim did Noah later correct?
- Which statement is current versus historical?
- Who does this fact belong to?
- Was this theory Noah-authored or AI-added?
- Which unresolved question remained unresolved?

- What did the source actually support?

### Metrics

Use the Continuity Fidelity Vector.

Add text similarity only as a secondary metric.

### Falsification

The initial Spine hypothesis fails if, under fair equal-budget conditions, the Spine does not outperform ordinary summarization/random/RAG baselines on continuity-relevant held-out tasks.

### Strong evidence

Strong evidence would require:

- pre-registered evaluation tasks,
- held-out data,
- repeated runs,
- statistical uncertainty,

## Experiment 3: Structured Memory Drift Test

### Core question

Does continuity-aware memory reduce contradiction and provenance failure over long conversations compared with ordinary RAG?

### Important conceptual correction

Do not define identity preservation as remaining close to a fixed historical embedding.

Humans legitimately change.

Therefore define:

```math
Drift = Illegitimate\ Drift + Legitimate\ Evolution
```

The system should suppress the first without suppressing the second.

### Illegitimate drift

Examples:

- contradicting an established fact without evidence,
- resurrecting a superseded belief,
- ignoring a correction,
- inventing an event,
- losing authorship provenance,
- changing relationship attribution,
- turning uncertainty into certainty,
- treating candidate architecture as canon.

### Legitimate evolution

Examples:

- changed preference,
- new evidence,
- revised value weighting,
- explicit reversal,
- learning,
- context-dependent choice,
- new life event.

### Conditions

Compare:

1. continuity-aware memory,
2. naive vector RAG,
3. rolling summary,
4. full available context where feasible.

### Primary metrics

- contradiction rate,
- correction loss rate,
- provenance error rate,

- number of turns until first serious continuity violation.

Embedding drift can remain a diagnostic, not the primary truth criterion.

### Falsification

If the structured memory architecture creates equal or more continuity violations than standard RAG, its additional complexity is not justified.

# 9. The most important scientific distinction: drift versus evolution

This distinction may become one of the strongest contributions of the framework.

Most persona-preservation systems implicitly treat stability as similarity to a frozen reference persona.

That is inadequate for a real person.

A person who changes after learning, aging, trauma, success, relationship changes, new evidence, or deliberate reflection has not necessarily experienced identity failure.

Therefore continuity cannot be measured as stationary resemblance.

A better framework tracks state transitions and their provenance.

Let:

```math
X_{t+1} = \Phi(X_t, O_t, C_t)
```

where:

- `X_t` = continuity state at time `t`,
- `O_t` = new observations/evidence,
- `C_t` = explicit corrections/decisions,
- `Phi` = state update process.

A valid evolution is one for which the transition has evidence and does not silently erase the prior state.

This implies a correction graph rather than a single mutable truth record.

Example:

```text
Assertion A at t1
   |
   +-- revised_by --> Assertion B at t2
                         |
                         +-- reaffirmed_at --> t3
```

The system can then answer both:

- What did Noah believe then?
- What does Noah say now?

without forcing either answer to erase the other.

# 12. The renderer boundary

The generative model is not the authority.

The renderer should receive structured context from provenance-aware systems and generate outputs subject to evidence constraints.

Recommended rule:

```text
RENDERER MAY SYNTHESIZE.
RENDERER MAY NOT SILENTLY PROMOTE SYNTHESIS INTO MEMORY.
```

The distinction between source evidence and rendered prose must survive every generation cycle.

This protects against a dangerous recursive contamination pattern:

```text
Noah idea
-> AI formalization
-> AI summary of formalization
-> another AI calls it established
-> summary is re-ingested as source
-> repeated claim appears independently verified
```

This failure mode is one of the central reasons provenance is part of continuity rather than optional metadata.

## 17.6 Can uncertainty itself be preserved as a memory feature?

A reliable continuity system should remember that some things were unresolved.

"I do not know" is sometimes part of the authentic state.

# 21. Scientific expansion path

The project should progress in layers.

## Layer 1: Ordinary, measurable features

Use explicit decisions, corrections, temporal links, provenance, relationships, uncertainty.

## Layer 2: Learned salience

Train or fit a model to predict which records are continuity-relevant based on held-out performance.

## Layer 3: Information-geometric features

Test Fisher/change geometry only after Layer 1 baselines exist.

## Layer 4: Topological features

Test TDA only if it contributes incremental predictive value.

## Layer 5: Dynamical stability

Define an explicit system state and evaluate drift-control behavior.

## Layer 6: Multi-person validation

Repeat on independent participants.

This order protects the research from becoming mathematically decorative before the basic signal is demonstrated.

# 22. Candidate formal definitions

## 22.1 Continuity record

A provenance-bound atomic record that captures an assertion, decision, correction, relationship, unresolved state, or event relevant to future longitudinal reconstruction.

## 22.2 Continuity state

The set or structured graph of currently active and historical continuity records, including correction lineage and provenance.

## 22.3 Continuity distortion

The measured loss or corruption of decision, correction, temporal, relational, provenance, or uncertainty information introduced by compression/reconstruction.

## 22.4 Continuity fidelity

Performance on a target family of longitudinal tasks under a defined memory representation.

## 22.5 Identity Spine

A sparse subset of continuity records selected to preserve target continuity fidelity within specified bounds under a constrained information budget.

## 22.6 False continuity

A state in which a system presents synthesized, misattributed, superseded, fabricated, or overconfident information as authentic longitudinal memory.

## 22.7 Legitimate evolution

A change in modeled identity state supported by new evidence, explicit revision, or context and preserved with provenance to the prior state.

## 22.8 Illegitimate drift

A change in modeled identity state caused by retrieval failure, provenance loss, hallucination, source contamination, untracked overwriting, or uncontrolled generation rather than evidence-backed evolution.

# 23. Candidate theorem direction, not yet theorem

A future theoretical target could be stated without pretending it is already proven:

> Under a defined continuity-task distribution, if a memory-selection policy preserves a sufficient statistic for those tasks, then additional corpus information that is conditionally irrelevant to the tasks can be compressed without increasing expected continuity distortion.

This connects the Identity Spine concept to sufficient statistics and rate-distortion ideas.

The hard research question is defining the task family broadly enough that the "sufficient" representation does not merely overfit a narrow benchmark.

That is an open problem.

# 24. Falsification criteria for the overall program

The project should explicitly record ways it can lose.

Evidence against the current core hypothesis would include:

1. Standard summaries consistently match or exceed continuity-aware representations at equal budgets.
2. Correction graphs do not reduce superseded-state errors.
3. Provenance tracking does not reduce false attribution.
4. Uncertainty-state retention does not improve calibration or unresolved-state fidelity.
5. Relationship-aware memory does not improve relational attribution.
6. Identity Spine selection fails to generalize beyond the data used to tune weights.
7. The same performance can be achieved by simpler recency/semantic heuristics.
8. Added geometry/topology features provide no incremental value after ordinary features are controlled.
9. Structured memory creates rigidity that prevents legitimate evolution.
10. Results fail on independent participants.

A framework that cannot specify failure conditions is not ready to call itself science.
