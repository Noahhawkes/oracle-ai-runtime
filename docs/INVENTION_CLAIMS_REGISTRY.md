* **SOV1**: The sovereign operating layer.
* **51/49 Human Sovereignty Rule**: Ultimate authority remains with the human user.
* **Search Light Compression Law**: Selective focus over raw data hoarding.
* **Continuity over Capture**: Preserving structural narrative, not raw data logging.
* **Observation ≠ Ownership**: Data processed by the system does not belong to the system.
* **Rendering ≠ Memory**: Ephemeral generation does not constitute permanent storage.
* **Sovereign Memory Gate**: Only the user decides what transitions into permanent memory.
* **Data Pipeline**: Raw Activity → Events → Context → Meaning → Memory → Retrieval → Action.
* **Staged Approvals**: Memory candidates must be approved before storage; action candidates must be approved before execution.
