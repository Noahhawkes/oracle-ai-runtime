## Five Field Layers

1. Spatial Attention Layer

   What it studies: where tools are placed, what remains visible, and which
   instruments receive primary attention.

   Example: ORACLE positioned as the local runtime body, Codex as the
   implementation hand, and external systems as auditors or contradiction
   surfaces.

2. Authority Allocation Layer

   What it studies: which system receives which class of command.

   Example: Codex receives repo changes, ORACLE receives live probes, Gemini or
   Grok receive audit prompts, and ChatGPT receives orientation synthesis.

3. Custody Layer

   What it studies: which claims have receipts, hashes, logs, screenshots, code
   diffs, tests, or durable storage references.

   Example: ORACLE port 7781, SQLite session persistence, custody counts,
   screenshot hashes, and pytest output.

4. Recursive Prompt Layer

   What it studies: how prompts propagate across systems and return as build
   directives, audits, corrections, or memory artifacts.

   Example: ChatGPT produces a Codex instruction, Codex patches the repo,
   ORACLE is retested, and external systems audit the thread drop.

5. Compression Risk Layer

   What it studies: where specificity is flattened into generic summary.

   Example risks: generic assistant boilerplate, fake action claims, lost source
   attribution, ungrounded continuity claims, and hallucinated provenance.
