## Purpose

VibeCode is the practical education lane for building with AI without losing
authority, context, or proof. It teaches people to convert human intuition into
constrained AI action, then verify the work through tests and receipts.

This package turns the source draft into a teachable masterclass bundle for the
AI Learning Center.

## Core Definition

```text
VibeCode is the discipline of converting human intuition into constrained AI
action, verified by tests and preserved by receipts.
```

Street version:

```text
Feel the drift. Name the target. Bound the machine. Run the test. Get the receipt.
```

## Course Promise

Students leave knowing how to control AI-assisted work instead of being dragged
by it.

They learn how to:

- Write cleaner build commands.
- Stop prompt pileups.
- Assign AI systems proper roles.
- Use receipts to verify work.
- Prevent hallucinated completion.
- Convert intuition into testable instructions.
- Run live acceptance checks.
- Keep drafts separate from final decisions.
- Protect authorship and source truth.
- Build faster without surrendering control.

## Governing Rule

```text
Receipts over vibes.
```

The vibe tells the operator where to look.
The receipt proves what happened.

## Human Authority Boundary

VibeCode does not teach AI worship, fake sentience, or surrender of authorship.
It teaches warm command, exact boundaries, and final human authority.

Core authority rule:

```text
The machine may carry weight, but the human keeps the keys.
```
