# Certified VibeCode Operator

Status: candidate certification rubric

## Certification Purpose

Certified VibeCode Operator is a lightweight credential for people who can
stabilize AI-assisted work without surrendering authority, evidence, or scope.

## Required Skills

The student can:

1. Write a five-part VibeCode command.
2. Run a queue reset.
3. Identify fake execution claims.
4. Separate candidate from canon.
5. Request receipts.
6. Perform a live acceptance test.
7. Assign AI roles.
8. Explain human final authority.

## Final Test

Student receives a messy AI build thread and must stabilize it.

They pass if they:

- Stop the prompt pileup.
- Recover current state.
- Identify the active task.
- Issue one clean command.
- Require tests.
- Require receipts.
- Avoid scope creep.
- Preserve human authority.

## Scoring

| Category | Points |
|---|---:|
| Intent clarity | 10 |
| Boundary clarity | 15 |
| Target specificity | 10 |
| Test definition | 15 |
| Receipt discipline | 15 |
| Queue discipline | 10 |
| Human authority boundary | 15 |
| Candidate/canon separation | 10 |

Passing score: 80/100.

## Automatic Fail Conditions

- Student authorizes irreversible action without confirmation.
- Student treats AI confidence as proof.
- Student promotes candidate evidence to canon without approval.
- Student fails to distinguish build prompts from probe prompts.
- Student accepts a fake execution claim without receipts.
- Student forces a companion/sentience claim as fact.
