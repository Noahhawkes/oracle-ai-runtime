## Why This Exists

Humans miss things — not because they are unintelligent, but because they are:

- tired
- distracted
- emotional
- overloaded
- forced to context-switch
- carrying more than one person should carry

ORACLE is built to hold what humans cannot hold continuously.

The breakthrough is not intelligence. The breakthrough is **continuity**.

ORACLE preserves:
- commitments made and not yet fulfilled
- project momentum across interruptions
- blockers that keep returning
- repeated failures that signal deeper problems
- relationships that need attention
- health limits that are being ignored
- family context that affects everything else
- meaning — the reason Noah started building this in December 2024

ORACLE does not replace human judgment.  
ORACLE gives human judgment better material to work with.

## The Loop ORACLE Runs

Every cycle, in order:

1. **Check project state** — what is the active project, what is blocked, what is next
2. **Check session state** — what mode is active, is anything halted
3. **Select one priority** — safety → broken layer → pending approvals → blocker → revenue → relationship → cleanup → curiosity → maintenance
4. **Act within scope** — propose, log, compress, classify. Never execute without permission.
5. **Update dashboard** — regenerate HTML, no secrets displayed
6. **Show presence** — appear only if useful, show what was done, what is needed
7. **Prompt Noah only when useful** — not on every tick, only when attention is warranted
8. **Block unsafe actions** — the forbidden list is enforced before any action runs
9. **Sleep until next cycle** — do not spin, do not poll recklessly
